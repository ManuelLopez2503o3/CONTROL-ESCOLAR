# CONTROL ESCOLAR

## Descripción
Sistema web para la gestión y administración escolar de una institución educativa.

## Objetivo
Facilitar el control de alumnos, profesores, pagos, becas, horarios, carreras y reportes académicos mediante una plataforma web.

## Pila tecnológica

- PHP
- MySQL
- HTML
- CSS
